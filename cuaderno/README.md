# Cuaderno de aprendizaje

Páginas HTML autocontenidas, una por etapa del proyecto. Cada una cuenta qué
se construyó, qué problema real apareció, qué hace la industria con ese
problema y termina con un cuestionario de opción múltiple.

| Página | Tema |
|---|---|
| `index.html` | Fases 0–1 (arquitectura, ingestion desde Infoleg) y Fase 2 (parser) |
| `parser.html` | Bitácora del parser: cada bug encontrado, cómo se detectó y cómo se testeó |

Se abren directo en el navegador, sin servidor.
